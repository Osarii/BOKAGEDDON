# BONKAGEDDON n8n Payload Contract

The frontend sends one `POST` per completed run when `VITE_N8N_WEBHOOK_URL` is configured.

Workflow webhook path:

- Test URL: `/webhook-test/bonkageddon/run-completed`
- Production URL: `/webhook/bonkageddon/run-completed`

## Request

```json
{
  "event": "bonkageddon.run.completed",
  "outcome": "gameover",
  "classification": "NORMAL_RUN",
  "playerName": "Survivor",
  "characterId": "bonk",
  "score": 1250,
  "kills": 42,
  "level": 4,
  "timeSurvivedSeconds": 215,
  "date": "2026-09-21T00:00:00.000Z"
}
```

## Fields

- `event`: must be `bonkageddon.run.completed`
- `outcome`: `gameover` or `victory`
- `classification`: optional frontend hint; workflow recomputes it after normalization
- `playerName`: required arcade handle, trimmed and capped to 20 characters by workflow
- `characterId`: `bonk`, `byte`, `tank`, `nova`, or `hex`
- `score`: numeric final score saved independently to JSON Server
- `kills`: numeric enemies defeated
- `level`: numeric final player level
- `timeSurvivedSeconds`: numeric run duration in seconds
- `date`: optional ISO timestamp generated by the browser

Do not add round, shield, or other future gameplay fields yet; they are not part of the current frontend payload.

## Validation

Invalid payloads return HTTP `400` from the explicit invalid branch:

```json
{
  "ok": false,
  "error": "Invalid BONKAGEDDON run payload",
  "errors": ["characterId must be one of bonk, byte, tank, nova, hex"],
  "receivedAt": "2026-09-21T00:00:00.000Z"
}
```

The workflow validates:

- expected event name
- supported `characterId`
- present `playerName`
- numeric `score`
- numeric `kills`
- numeric `level`
- numeric `timeSurvivedSeconds`
- supported `outcome`

## Classification

- `LEGENDARY`: victory, score >= 50000, or kills >= 500
- `HIGH_SCORE`: score >= 10000, level >= 10, or kills >= 100
- `NORMAL_RUN`: everything else

Valid payloads continue through normalization, run analysis, classification branching, action processing, and success response.

## Success Response

```json
{
  "ok": true,
  "classification": "NORMAL_RUN",
  "action": "archive_standard_run",
  "badge": "RUN LOGGED",
  "summary": "Survivor finished a gameover run.",
  "receivedAt": "2026-09-21T00:00:00.000Z"
}
```
